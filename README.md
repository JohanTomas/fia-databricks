# FIA - Databricks GitHub Integration

Proyecto académico desarrollado para la asignatura **Fundamentos de Inteligencia Artificial (FIA)**.

## Descripción

Este proyecto tiene como finalidad demostrar la integración de herramientas de control de versiones, automatización y procesamiento de datos mediante **GitHub, GitHub Actions y Databricks**.

Durante el desarrollo se implementarán diferentes integraciones y funcionalidades solicitadas en la actividad académica.

## Objetivos

* Crear y administrar un repositorio GitHub.
* Integrar GitHub con Databricks mediante un Git Folder.
* Implementar un flujo automatizado mediante GitHub Actions.
* Configurar diferentes conexiones de datos y servicios.
* Instalar y utilizar Databricks CLI desde el equipo local.
* Utilizar un Databricks Volume para almacenar archivos.
* Documentar mediante evidencias el funcionamiento de cada componente.

## Tecnologías

## Actividades

### 1. Integración GitHub + Databricks

Se configurará un Git Folder de Databricks conectado con el repositorio GitHub.

### 2. Conexiones externas

Se configurarán tres conexiones diferentes para demostrar la integración de Databricks con diferentes fuentes o servicios.

### 3. Databricks CLI

Se instalará y configurará Databricks CLI en el equipo local para realizar operaciones mediante terminal.

### 4. Databricks Volume

Se utilizará un Volume para almacenar archivos de prueba, incluyendo imágenes y documentos PDF.
